# 관리하는 남자 — 아이폰 설치 방법

개인용 자기관리 웹앱(PWA)이에요. 아이폰 Safari에서 '홈 화면에 추가'하면 앱처럼 쓸 수 있어요.
기록과 사진은 **내 아이폰 안에만** 저장되고, 어디로도 전송되지 않아요.

## 1. GitHub Pages에 올리기 (무료, 한 번만)

1. github.com에서 무료 계정을 만들고 로그인해요.
2. 오른쪽 위 **+ → New repository**를 눌러요.
   - Repository name: `gwanri` (원하는 이름 아무거나)
   - **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
4. 압축을 푼 폴더 안의 파일을 **전부** 끌어다 놓아요.
   (`index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icons` 폴더)
   → 아래 **Commit changes**를 눌러요.
5. 저장소의 **Settings → Pages**로 가요.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
6. 1~2분 뒤 같은 화면 위쪽에 주소가 떠요.
   예: `https://내아이디.github.io/gwanri/`

> 저장소는 공개지만, 올라가는 건 앱 코드뿐이에요. 내 기록과 사진은 코드에 없고 아이폰에만 있어요.

## 2. 아이폰에 설치하기

1. 아이폰 **Safari**로 위 주소를 열어요. (크롬 말고 Safari)
2. 아래 가운데 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**.
3. 홈 화면의 '관리하는 남자' 아이콘으로 실행해요.
   이제 주소창 없이 앱처럼 열리고, 인터넷이 없어도 열려요.

## 3. 꼭 알아 둘 것

- **백업**: 앱을 지우거나 Safari 데이터를 지우면 기록도 지워져요.
  가끔 **설정 → 백업 파일 저장**으로 파일을 '파일' 앱이나 iCloud Drive에 저장해 두세요.
  새 폰으로 옮길 때도 **설정 → 백업에서 복원**을 쓰면 돼요.
- **알림**: 웹앱이라 정해진 시간에 울리는 알림은 없어요. 대신 오늘 화면에 '권장 체크 시간'이 보여요.
  알림이 필요하면 아이폰 '미리 알림'이나 '단축어 → 개인용 자동화'로 같은 시간에 앱을 여는 알림을 만들 수 있어요.
- **사진**: '사진 촬영 · 업로드'를 누르면 카메라로 찍거나 사진 보관함에서 고를 수 있어요.
  사진은 줄여서(긴 변 1280px) 앱 안에만 저장돼요.
- **업데이트**: 파일을 새 버전으로 바꿔 올리면, 앱을 다음에 열 때(인터넷 연결 상태) 반영돼요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 시작 화면 |
| `app.js` | 모든 화면과 기능 |
| `style.css` | 디자인 |
| `manifest.webmanifest` | 홈 화면 앱 이름·아이콘 |
| `sw.js` | 오프라인 실행 |
| `icons/` | 앱 아이콘 |
